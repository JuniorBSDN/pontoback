PontoBack: Gestão Modernizada via
QR Code Scanner

Uma solução full-stack para registro de ponto de funcionários, integrando um painel administrativo intuitivo com um terminal de tablet rápido e seguro.

Ver Detalhes do Projeto

Visão Geral do Sistema

O Problema

Muitas empresas ainda dependem de sistemas biométricos caros, difíceis de manter ou, pior, planilhas manuais. Isso gera fraudes, erros de cálculo e uma carga administrativa enorme para o RH.

A Solução

Desenvolvi o PontoBack como uma plataforma web integrada de dois módulos:

  • Painel Gestor: Cadastro e gestão centralizada.
  • Terminal Tablet: Registro rápido via câmera.

Stack Tecnológico

O Fluxo de Experiência do Usuário (UI/UX)

O sistema foi projetado para ter uma curva de aprendizado zero para o funcionário e ser extremamente eficiente para o gestor.

Perspectiva do Gestor

1. Dashboard Central e Login Seguro

Começamos no Painel Gestor. O login administrativo (imagem inferior) garante a segurança. Uma vez logado, o gestor tem uma visão clara de todos os funcionários cadastrados, seus setores e salários. Esta tela central é o ponto de partida para qualquer ação.

Cadastro de Novo Funcionário

Ao clicar em "+ Novo Funcionário", um formulário modal limpo e focado se abre. Aqui, o gestor preenche os dados essenciais em uma interface projetada para minimizar erros de digitação.

Transição Administração ⇒ Funcionário

2. Geração do Cartão de Ponto

Imediatamente após o cadastro, o sistema gera um "Cartão QR Code" único para o funcionário. Esta tela modal permite que o gestor visualize o código e clique em "Imprimir Cartão" para entregar ao funcionário sua credencial de ponto física ou digital.

Perspectiva do Funcionário - O Terminal

3. Registro de Ponto via Câmera

O módulo Terminal (Tablet) é configurado uma única vez na unidade. Após a ativação, o terminal fica em modo de "espera ativa". O funcionário simplesmente aponta seu Cartão QR Code para a câmera. O sistema detecta o código e registra a entrada ou saída instantaneamente, sem botões ou senhas.

Relatórios e Transparência

4. Folha de Ponto Individual

De volta ao Painel Gestor, o RH acessa a Folha de Ponto Individual de qualquer funcionário. Esta interface permite filtrar por data e exibe um log detalhado de todas as Entradas e Saídas, calculando automaticamente a duração e o total de horas no período.

Os status são coloridos (Verde/Azul) para facilitar a leitura e auditoria.

Relatórios em PDF

Gere espelhos de ponto profissionais em segundos. O algoritmo em Python processa todas as jornadas e entrega um documento pronto para assinatura e contabilidade, perfeitamente formatado para impressão ou exportação.

  • Exportação Direta via Navegador
  • Validação Automática de Horas
  • Layout Padrão MTP (Portaria 671)

CONFORMIDADE JURÍDICA

Portaria 671 (MTP)

Atendemos aos requisitos de registro eletrônico (REP-P), garantindo que os dados originais jamais sejam alterados sem rastro de auditoria.

LGPD & Segurança

Dados criptografados via Firebase Auth e Firestore, com políticas de privacidade alinhadas à Lei Geral de Proteção de Dados.
